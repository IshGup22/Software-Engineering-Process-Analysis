# Roles and Responsibilities

## Overview

This document clarifies stakeholder responsibilities across the future-state software change request workflow.

Clear ownership helps reduce ambiguity during handoffs and supports accountability throughout the software delivery lifecycle.

## Responsibility Matrix

| Activity | Business Requester | Business Analyst | Product Owner | Engineering | Development | QA | Business Approver |
|---|---|---|---|---|---|---|---|
| Submit change request | R | C | I | I | I | I | I |
| Validate request completeness | C | R | I | I | I | I | I |
| Clarify business requirements | C | R | C | C | I | I | I |
| Document requirements | C | R | C | C | I | I | I |
| Review technical feasibility | I | C | C | R | C | I | I |
| Prioritize backlog | I | C | R | C | I | I | I |
| Sprint planning | I | C | C | C | R | C | I |
| Develop change | I | C | I | C | R | C | I |
| Define acceptance criteria | C | R | C | C | C | C | C |
| Execute testing | I | C | I | C | C | R | I |
| Resolve defects | I | C | I | C | R | C | I |
| Perform business acceptance | C | C | I | I | I | C | R |
| Mark ready for release | I | C | R | C | C | C | C |

## RACI Legend

- **R — Responsible:** Performs the activity
- **A — Accountable:** Ultimately owns the outcome
- **C — Consulted:** Provides input
- **I — Informed:** Kept aware of progress

This project uses a simplified responsibility matrix to demonstrate role clarity across the redesigned process.

## Key Ownership Improvements

The future-state workflow improves role clarity by:

- Assigning requirement validation to the Business Analyst
- Assigning backlog prioritization to the Product Owner
- Assigning technical feasibility review to Engineering
- Assigning development responsibility to the Development Team
- Assigning test execution to QA
- Assigning final business acceptance to the Business Approver
- Establishing clearer ownership at each major workflow stage

These responsibilities are proposed process-design roles rather than measured organizational assignments.
